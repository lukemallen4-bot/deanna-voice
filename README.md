# Deanna's Voice

A simple picture talking board (AAC app) for an Android tablet. Big picture buttons speak words out loud, a sentence bar reads whole sentences, and a PIN-locked caregiver mode lets you edit every page, add photos, and adjust touch settings.

- `index.html`: the app (installable, works offline)
- `sw.js`, `manifest.webmanifest`, icons: install and offline support
- `source.html`: the same app without the install wrapper, for previewing

Pictures and settings are stored only on the tablet, never in this repository.
